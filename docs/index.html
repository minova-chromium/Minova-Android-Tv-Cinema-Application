01 One library

What is
Minova Cinema?

Minova Cinema is an independent Plex client for the movies and shows on your own Plex Media Server. It gives Android phones, tablets, Android TV, Google TV, and Windows PCs one consistent, private viewing experience—without a Minova account.

05 Good to know

Before the
opening frame.

Is Minova Cinema made by Plex?

No. Minova Cinema is an independent client that connects to Plex Media Server. Plex is a trademark of Plex, Inc.

Is the Android download the same for phones and TVs?

Yes. The signed APK detects the device and presents the touch-first phone/tablet interface or the remote-first television interface.

What does the Windows installer include?

It includes the desktop interface, Electron runtime, a native Windows libmpv playback host, and the required media runtime. It supports 64-bit Windows 10 and 11.

Does every file Direct Play?

Direct Play depends on the codecs and tracks supported by the device. Minova can request Plex conversion when the original source is incompatible.

Where do I find my Plex token?

Follow the step-by-step Plex guide →. Treat the token like a password and never post it publicly.
