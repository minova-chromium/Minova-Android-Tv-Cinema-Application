Privacy notes

Your server stays
your server.

A plain-language summary of what Minova Cinema needs to connect to Plex and what the application does with that information.

Information stored on the TV

Minova Cinema stores the Plex server address and token that you provide during setup in the application’s private local preferences. These values are used to authenticate requests to your Plex Media Server.

Network communication

The application communicates with the Plex server address you configure. Artwork and media may be requested from that server. Plex features can cause your Plex server or account to communicate with services operated by Plex, Inc.; those services are governed by Plex’s own terms and privacy policy.

Minova accounts and analytics

Minova Cinema does not require a Minova account. The current application does not include an advertising SDK or a Minova-operated analytics service.

Watch state and watchlist

When you mark an item watched, resume playback, or change the Plex watchlist, the application sends that action to Plex so the state can remain consistent with other Plex clients.

Your responsibility

A Plex token grants access to your server. Keep it private, use a trusted local network, and do not include it in public bug reports. If a token is exposed, revoke it through Plex and replace it on the TV.

Questions or reports

Open a privacy or security report through the project’s GitHub security page ↗. For normal bugs or feature ideas, use the feedback form →.
