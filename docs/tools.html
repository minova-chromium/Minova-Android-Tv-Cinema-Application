Kometa Helper

A desktop control panel for Plex and Kometa. Build collections from public IMDb lists, choose their posters, and add information overlays to movie and show artwork—all from one place.

  • IMDb collections
  • Collection posters
  • Movie & show overlays

Runs on your Windows computer with a local Kometa installation. Docker is not required. Changes are applied to Plex; refresh your library in Minova Cinema to see them on phone, tablet, TV, or desktop.

01 First run

From download
to connected.

Have Windows 10 or 11, Python 3.11 or newer, a running Plex Media Server, your Plex token, and a TMDb API key ready. Internet access is needed to install or update Kometa and search for artwork.

  1. Extract and open the app

    Download the Windows ZIP above and extract the whole folder to a permanent location, such as C:\Kometa Helper. Run Kometa Helper.exe from that extracted folder.

  2. Install or update Kometa

    Open the Setup tab and select Install / Update Kometa. The helper manages a local Kometa installation for the work you run from the app.

  3. Connect your Plex server

    Enter your server URL and token, then select Save + Test Plex. Use http://127.0.0.1:32400 only when Plex runs on the same computer as the helper. For another computer or NAS, use its address, such as http://YOUR-SERVER-IP:32400.

    Need the address or token? Follow the Plex connection guide.

  4. Add your TMDb key and libraries

    Paste your TMDb API key, select Save TMDb Key, and choose the Plex libraries that Kometa should manage.

  5. Save your media folders

    Add all the movie and show folders to use for Plex refreshes. Select them with Browse Movie Folder and Browse Show Folder, or enter one folder path per line. The app remembers your last tab after setup.

Enter credentials in the Windows app. The helper can save Plex tokens, media paths, logs, and generated artwork on your computer. Keep its runtime folder private when sharing files or asking for help.
02 Everyday tools

Collections with
their own character.

  1. Create a collection from an IMDb list

    Open Add IMDb and paste a public list ID, such as ls006405458, or its full URL, https://www.imdb.com/list/ls006405458/. Review the preview before creating the collection. When a TMDb collection match is available, the helper can use it as an alternative to IMDb scraping.

    The helper hides the created collection tile from Plex's normal library grid. Look in the collections view to browse it.

  2. Manage the collections you created

    The Collections tab lists collections created through the helper. From there, update a collection or open its poster tools. Deleting an entry removes both the saved collection and the collection in Plex.

  3. Choose and apply a collection poster

    Use the poster tools to generate a layout, search for a logo or poster artwork, or upload a custom poster. Apply your choice directly to the Plex collection. Minova Cinema's Collections tab displays the poster assigned to that collection in Plex.

Individual movies & shows

Add useful details to your posters.

In Posters → Global Overlay Setup, enable and position resolution, audio codec, video format/source, or show-status overlays. Save your choices, then run Refresh All Posters.

These badges belong on individual movie and show posters. Collection posters stay separate from the global overlay badges.

03 Refresh & maintain

Keep your library
looking its best.

  1. Refresh posters when you're ready

    Open Posters and select Refresh All Posters. The helper asks Plex to rescan the configured movie and show folders, then runs Kometa for Movies and TV Shows. Use this after changing overlay settings.

  2. Set an optional daily schedule

    In Setup, enter a time such as 05:00 and select Create Daily Schedule. Windows Task Scheduler then runs the all-poster refresh workflow daily.

Plex won't connect

Confirm Plex is running, the server URL and token are correct, and Windows Firewall allows the connection. If Plex is on another device, use that device's address instead of 127.0.0.1.

An IMDb collection has fewer titles than expected

A list may include unreleased titles or titles that aren't in your Plex library. Check that a missing title exists in Plex and has correctly matched metadata. A TMDb collection fallback may be available.

A poster refresh finishes but nothing changes

Check your library selection, saved media folders, Kometa configuration, and enabled global overlays. Also confirm that the affected Plex titles have correctly matched metadata.

Where does the helper save its files?

Runtime files live in %USERPROFILE%\Documents\Kometa-Helper\runtime, including saved collections, tab state, media folder locations, logs, and generated poster/logo cache.

The documented defaults are Documents\Kometa for Kometa and Documents\Kometa-Quickstart\config\jolly_goodall_config.yml for its Quickstart configuration.

How do I reset the remembered tab?

Close the helper, then delete only Documents\Kometa-Helper\runtime\ui-state.json. This resets its remembered tab.
